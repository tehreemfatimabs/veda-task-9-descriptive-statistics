# VEDA Technology Task 9: Descriptive Statistics Primer

## Project Overview

This project explores descriptive statistics using Python, Pandas, and the Titanic passenger dataset. It summarizes numerical variables to understand their central tendency, variability, and distribution.

## Objectives

- Calculate mean, median, mode, and standard deviation.
- Analyze percentiles and the spread of the middle 50% of observations.
- Investigate missing values and potential skewness.
- Visualize numerical distributions using histograms.
- Interpret statistical findings in a clear, professional manner.

## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## Dataset

The project uses the Titanic training dataset from Kaggle's Titanic: Machine Learning from Disaster competition.

Dataset source: https://www.kaggle.com/competitions/titanic/data

The analysis focuses on four numerical variables: Age, Fare, SibSp, and Parch.

## Project Files

- `descriptive_statistics.ipynb` — Analysis, code, visualizations, and interpretation.
- `summary_statistics.csv` — Exported summary statistics.
## Key Findings

The analysis compares means and medians to investigate potential skewness, uses standard deviation to assess variability, and examines percentiles to understand the spread of the central 50% of observations.

Age contains missing values, which are documented in the analysis. Histograms provide additional evidence for interpreting the distributions.

## Conclusion

This project demonstrates how descriptive statistics and data visualization can help transform raw numerical data into meaningful insights. It also highlights the importance of checking missing values and interpreting statistical measures in context.
